## 4. 核心机制 (core-mechanism)

**一句可验证的话**: 烟幕云团球心C(t)在导弹M(t)与真目标圆柱之间形成遮蔽视锥(半顶角α=arcsin(R/d)),当且仅当圆柱上下底面圆周所有点的视角β≤α时,目标被完全遮蔽;优化无人机航向θ、航速v、投弹时序(t_rel,Δt)使遮蔽时间并集最大化。

**五层展开**:
- 对象层: 导弹M_k、无人机FY_i、烟幕弹D_{i,j}、真目标圆柱A、烟幕云团球C
- 状态层: 各对象在时刻t的三维位置r(t)
- 机制层: 视锥遮蔽判定 β_max(t)≤α(t)
- 决策层: θ_i, v_i, t_rel, Δt_fuse, 任务分配y
- 评价层: 遮蔽时间并集 T = ∫∨E(t)dt

## 6. 模型规格 (model-interfaces)

### 模型一:运动学(解析,全题通用)

**导弹 M_k(t)**:
```
M_k(t) = M_k^0 + 300·t·s_Mk
s_Mk = (O - M_k^0) / |O - M_k^0|      (单位向量指向原点)
M1: M1(t) = (20000-298.5t, 0, 2000-29.9t), 命中t_f=66.7s
```

**无人机 FY_i(t)**:
```
FY_i(t) = FY_i^0 + v_i·t·(cosθ_i, sinθ_i, 0)
v_i ∈ [70,140], θ_i ∈ [0, 2π)
```

**烟幕弹 D_{i,j} 起爆点**:
```
r_burst = FY_i(t_rel) + v_i·Δt·(cosθ_i, sinθ_i, 0) - (0, 0, 4.9·Δt²)
```

**云团球心 C(t)** (t≥t_burst):
```
C(t) = (x_burst, y_burst, z_burst - 3·(t - t_burst))
```

### 模型二:遮蔽判定(严格视锥)

**遮蔽半顶角**:
```
α(t) = arcsin(R / d(t)),  d(t) = |M(t) - C(t)|,  R=10
```

**目标最大视角** (对上下圆周参数化搜索):
```
P_top(φ) = (0,200,10) + 7·(cosφ, sinφ, 0)
P_bot(φ) = (0,200,0) + 7·(cosφ, sinφ, 0)

β(φ,t) = arccos( (MP·MC) / (|MP|·|MC|) )
β_max(t) = max_{φ∈[0,2π), top/bot} β(φ,t)
```

**有效遮蔽判据**:
```
E(t) = 1  if  β_max(t) ≤ α(t)  else  0
```

**单弹遮蔽时长** (Δt=0.001s步进):
```
T_{i,j} = Σ E(t_n)·Δt,  t_n ∈ [t_burst, t_burst+20]
```

### 模型三:优化(MINLP)

**目标**: max T = ∫₀^tf [∨_{i,j} E_{i,j}(t)] dt  (并集)

**约束**:
```
70 ≤ v_i ≤ 140
t_rel,j+1 ≥ t_rel,j + 1          (同机相邻弹间隔≥1s)
Δt_j ≥ 0                          (引信非负)
z_FYi - 4.9·Δt_j² ≥ 0            (起爆点不穿地)
t_burst ≤ 66.7s                   (命中前起爆)
Σ_k y_{i,j,k} ≤ 1                (Q5:一弹至多干扰一弹)
```

## 8. 方案选优 (proposal-selection)

### 四篇范文方案对比

| 维度 | A1(DeepSeek) | A2(视锥) | A3(分层SLSQP) | A4(DEGA) |
|---|---|---|---|---|
| 遮蔽判定 | 点到线段距离(质点) | 视锥角+圆周(严格) | 表面采样点 | 表面采样+射线 |
| 判定精度 | 宽松(高估) | 严格(精确) | 近似(可控) | 近似(可控) |
| Q1结果 | 1.41 | 1.3916 | 1.392 | 1.391 |
| Q2算法 | 未明 | PSO-SQP | 网格+SLSQP | GA+剪枝 |
| Q3算法 | 未明 | PSO-SQP | SBX-GA | DEGA |
| Q5策略 | 15弹10有效 | 一机一弹(过简) | 场景分类 | 分组+分层 |
| Q5结果 | 42.20 | 20.40 | 22.87 | - |
| 可写论文 | 流程化 | 证明优雅 | 分层清晰 | 算法扎实 |

### 选优结论

**胜者: A2(视锥判定) + A4(DEGA/分层) + A1(数值目标) 混合方案**

理由:
1. 遮蔽判定取A2视锥模型:有严格几何证明(凸集→上下圆周),精度无损,论文加分
2. 优化算法取A4 DEGA+分层:差分进化防局部最优,分层降低维度,工程可行
3. 数值目标取A1:Q1=1.41/Q2=4.68/Q3=7.56/Q4=13.91作为对标(但用严格判定重新计算)
4. 不取A1的宽松判定(会高估);不取A2的Q5简化(一机一弹,偏低)
